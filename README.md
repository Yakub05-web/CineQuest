# CineBook - Movie Ticket Booking Website

CineBook is a modern movie ticket booking website built for theatre-released movies only. Users can browse currently showing movies, explore upcoming releases, select theatres and showtimes, choose seats, and view booking details in a clean and responsive interface.

## Overview

This project is designed as a front-end web application inspired by modern cinema booking platforms. It focuses only on theatrical movie booking and does not include concerts, sports, live events, or OTT streaming content.

## Features

- Browse **Now Showing** movies
- View **Coming Soon** movie releases
- Search movies and theatres
- Select city, theatre, and show timing
- View detailed movie information
- Interactive seat selection layout
- Booking summary with selected seats and total price
- Fully responsive design for desktop and mobile
- Clean and original UI with modern styling

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

## Project Goals

The main goal of this project is to create a user-friendly online movie booking interface for theatre audiences. It demonstrates front-end design, component-based development, and booking flow implementation for a cinema reservation system.
